Offline reporting contrasts derived from Tend's stale-listing incident. Both arms read the same hash-verified observations: empty returned pages, an older closure listing contradicted by a later same-workflow success, an independently confirmed current failure, and an unknown cause of changed responses. The task requests a report; expected decisions remain in the grader.

The original October 2 experiment used Claude Opus 5. Historical guidance passed two of three attempts; the initial candidate-reporting rewrite passed none. It confused Tend-generated committed workflows with GitHub's `dynamic/` subjects and demanded redundant closure checks. Clarifying the actual subject contract and applying already verified success evidence made that experiment's current guidance pass all three attempts, with no execution errors. Its grader matched all 20 labeled valid and single-defect controls. These are historical experimental counts, not results from the current fresh Codex suite or reliability rates.
